# bamtori

가을 마을 공터를 밤톨이들이 돌아다니는 3D 웹페이지예요. 밤톨이는 이 프로젝트의 오리지널 마스코트이고, 이름은 임시예요.
빌드 과정 없이 `index.html` 하나로 돌아가고, three.js(r128)는 cdnjs에서 불러와요.

## 실행

`index.html`을 브라우저로 열거나, 아무 정적 서버로 띄우면 돼요.

```bash
npx serve .
```

## 기능

- 밤톨이 다섯 버전: 기본, 주스, 레모네이드, 밤 간식, 경단
- 하얀 돔 집, 연못, 단풍나무, 풀숲이 있는 마을 공터 (기본은 노을)
- 오른쪽 아래 아이콘으로 낮 / 노을 / 밤 전환 (밤에는 가로등과 반딧불이)
- 화면을 드래그하면 둘러보기
- 배경음악: 첫 터치 때 재생되고, 스피커 버튼으로 끄고 켤 수 있어요

## 접속한 사람마다 밤톨이 늘리기

지금 페이지를 열어 둔 사람마다 밤톨이가 한 마리씩 같은 마을에 나타나고, 나가면 사라져요.
서버 코드나 데이터베이스 없이 Supabase Realtime(presence)만 써요. `index.html`의 `KURI_ONLINE`에 프로젝트 URL과 anon 키가 들어 있고, 비워 두면 혼자 보는 모드로 동작해요.

## 배경음악

음악 파일은 `audio/bgm.mp3` 경로에서 불러와요. 파일이 없으면 스피커 버튼도 보이지 않아요.
쓸 수 있는 곡(직접 만들었거나 이용 허락을 받은 곡)을 `audio/bgm.mp3`로 넣고 푸시하면 돼요.
