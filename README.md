# kurimanju

가을 숲속 공터를 쿠리만주가 돌아다니는 3D 웹페이지예요. 빌드 과정 없이 `index.html` 하나로 돌아가고, three.js(r128)는 cdnjs에서 불러와요.

## 실행

`index.html`을 브라우저로 열거나, 아무 정적 서버로 띄우면 돼요.

```bash
npx serve .
```

## 기능

- 쿠리만주 다섯 버전: 기본, 캔음료, 레모네이드("하―!"), 밤만쥬 먹기, 소시지
- 오른쪽 아래 아이콘으로 낮 / 노을 / 밤 전환 (밤에는 가로등과 반딧불이)
- `+` 버튼으로 쿠리만주 추가 (내 화면에서만)
- 화면을 드래그하면 둘러보기

## 접속한 사람마다 쿠리만주 추가

claude.ai 아티팩트로 열면 `room` 기능을 써서, 지금 페이지를 보고 있는 사람마다 무작위 버전의 쿠리만주가 같은 숲에 나타나요.
일반 웹사이트로 배포하면 그 기능이 없어서 혼자 보는 모드로 동작해요. 일반 사이트에서도 같이 보이게 하려면 실시간 서버(WebSocket 등)를 붙여서 `syncPeers()`에 접속자 목록을 넘겨주면 돼요.
